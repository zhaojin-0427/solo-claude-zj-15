# 家具入户推演台

刚搬进合租房前，在本机推演桌、柜、床能否穿过楼道、房门并放到预定位置。

- **后端**：Python 3 标准库（`http.server` + `sqlite3`），无第三方依赖
  （本机没有 Flask / pip / root 权限，故用标准库实现了与 Flask 等价的 JSON API）。
- **前端**：原生 HTML / CSS / JavaScript + SVG，带标尺网格、平移缩放、捕捉。
- **存储**：SQLite，文件位于 `data/schemes.db`，自动创建。

## 启动

```bash
python3 app.py
# 打开 http://127.0.0.1:8000
```

点击顶栏「**载入示例户型**」即可获得一个「楼道走廊 + 卧室 + 房门 + 管井 + 床/衣柜/书桌」的完整示例。

## 三个工作页

### ① 户型
- 左侧工具画 **房间/走廊**（拖矩形）、**门洞**（沿墙边拖线）、**固定障碍**。
- 点击要素在右侧改：空间净高、门洞净宽、门楣净高、最大开启角、开启侧（扇形即门扇扫掠范围）；障碍可旋转。
- 画布滚轮缩放、Alt/右键拖动平移，所有尺寸以 mm 计，网格 100 mm、粗线 1 m，右下角有比例尺。

### ② 家具 / 路线
- 填家具 **长 × 宽 × 高** 添加；在画布空白处点击添加 **关键姿态**，拖动姿态本体平移，拖蓝色圆点旋转。
- 可设置每个姿态的 **抬起角**，实时显示倾斜后的有效竖向高度。
- 拖动/编辑时自动调用后端检查：门扇开启范围、转角扫掠、通道净宽、抬升高度、与墙或其他家具碰撞。
- 「▶ 播放路线」沿姿态插值动画移动，**停在首个冲突**，在冲突点画红圈并以气泡标出剩余/侵入尺寸，底部提示条给出类型与最小侧隙。
- 路线可行后可「用路线终点作为摆放位」，再为家具设置 **柜门 / 抽屉 / 椅子入座空间** 三类使用包络（绿色虚线区），摆放其他家具时会把这些空间当作阻挡。

### ③ 摆放优化
- 勾选 **锁定** 的物件（如床，锁定前需已有摆放位），系统只调整其余家具。
- 按以下优先级对候选方案排序：
  1. **全部家具可达**（每件家具从入户门有 A\* 网格搬运路径，避开锁定物）；
  2. **最小通行余量**（路径到墙/障碍的最小侧隙，越大越好）；
  3. **转向次数**（A\* 路径转弯数，越少越好）；
  4. **占地紧凑度**（家具占地 / 包围盒面积）。
- 点击方案卡片预览（绿色家具 + 橙色路径），「采用此方案」写入摆放位。

## 检查规则（`planner.py`）

| 检查 | 方法 |
|---|---|
| 撞墙 | 墙段沿空间边生成、门洞沿所有贴合边剪开；墙身中点进入家具凸多边形且法向穿透 > 20 mm |
| 转角扫掠 | 相邻姿态四角取凸包作为移动包络，与墙/障碍做 SAT 相交 |
| 门扇 | 门绕门轴的扇形三角扇近似；过门段视为门已固定全开，仅全开扇叶是障碍 |
| 通道净宽 | 从姿态中心沿运动法向向两侧射线探测到墙/障碍的距离 |
| 抬升高度 | `h·cos(pitch) + max(w,d)·sin(pitch)`，与门楣净高、空间净高比较 |
| 门洞宽度 | 家具扫掠包络在门洞方向的投影不得大于门宽 |
| 碰撞 | 凸多边形 SAT，给出穿透深度（即“剩余尺寸”） |

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/schemes` | 方案列表 |
| POST | `/api/schemes` | 新建/更新（带 `id` 为更新） |
| GET/DELETE | `/api/schemes/<id>` | 读取 / 删除 |
| POST | `/api/check/pose` | 单姿态检查（拖动时） |
| POST | `/api/check/route` | 整路线检查，返回首个冲突与扫掠包络 |
| POST | `/api/usage` | 使用包络多边形 |
| POST | `/api/optimize` | 布局搜索与评分排序 |

## 文件

```
app.py          HTTP 服务、SQLite、API 组装
geometry.py     2D 计算几何（SAT、凸包、射线、扫掠包络）
planner.py      户型/门/姿态模型与全部碰撞检查
optimizer.py    栅格 A* + 候选摆放生成 + 四指标评分
smoke_test.py   后端冒烟测试（python3 smoke_test.py）
static/         前端（index.html、css、svg-editor.js、app.js）
data/           SQLite 数据库（自动创建）
```
